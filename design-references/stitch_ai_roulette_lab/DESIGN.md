## Brand & Style

This design system establishes an ultra-refined, high-precision aesthetic tailored for autonomous AI simulation, risk modeling, and algorithmic execution. The interface balances high-stakes gaming mathematics with advanced enterprise software tooling, projecting calculated mastery, absolute transparency, and academic rigor.

The visual direction merges **Minimalist Modernism** with **Analytical Tactility**:
- Crisp white operational modules float over warm architectural ivory backdrops, eliminating the aggressive eye fatigue of pure white while maintaining high-contrast daylight legibility.
- Visual cadence is driven by technical telemetry: structured data grids, monospaced runtimes, real-time agent decision traces, and probability distributions.
- Broadcast-grade clarity ensures that dense numeric displays, decision trees, and wheel physics streams remain immediately legible in high-resolution video captures and live presentations.

## Colors

The palette leverages an editorial, warm architectural foundation punctuated by vibrant technical accents and heritage casino signifiers:

- **Base Canvas & Surfaces**: The background layer is anchored in warm ivory (`#FBF9F5` / `#F6F4EE`), establishing an analog paper-like substrate. Card containers, tables, and modal layers sit on pure optical white (`#FFFFFF`) to produce clear structural definition without harshness.
- **Ink & Typography**: Deep slate ink (`#1E293B`) anchors primary headings and key values, while muted slate (`#475569` and `#64748B`) handles analytical labels, metadata, and structural microcopy.
- **Algorithmic Accents**:
  - **Primary (Teal - `#0D9488` / `#14B8A6`)**: Signifies active agent telemetry, system loops, heuristic exploration, and primary execution triggers.
  - **Secondary (Indigo - `#4F46E5` / `#6366F1`)**: Reserved for deep model inference, neural state tracking, parameter settings, and long-range probability curves.
- **European Roulette Domain Accents**:
  - **Zero / Equilibrium (Emerald - `#059669`)**: Highlights zero-slot states, algorithmic yield positive events, and stability markers.
  - **Roulette Red (Crimson - `#DC2626`)**: Direct wheel red tracking, active risk warnings, and drawdown alerts.
  - **Roulette Black / Low (Charcoal Slate - `#1E293B`)**: Grounded neutral state, wheel black sector outcomes, and settled parameters.
- **Borders & Dividers**: Crisp hair-thin lines (`#E2E8F0`) separate data columns, modular cards, and chart axis boundaries.

## Typography

Typography establishes an immediate dual-hierarchy: structural prose and interface communication rely on **Inter**, while technical readouts, probability tensors, agent logs, and runtime telemetry utilize **JetBrains Mono**.

- Headings use tightened negative tracking to project density and authority.
- All numeric readings, balance changes, win percentages, table stakes, and roulette outcome logs must be rendered in `JetBrains Mono` with tabular lining figures enabled (`tnum`) to eliminate layout shift during live automated updates.
- Section tags, statuses, and agent heuristics utilize micro-caps or uppercase labels set in `label-sm` with slight positive tracking for crisp optical separation.

## Layout & Spacing

The layout is built upon an adaptive 12-column fluid grid configured to support dense dashboard monitors, analytical live streaming, and compact mobile views:

- **Desktop (>= 1280px)**: 12-column matrix with `gutter-desktop` (24px) and outer `margin-desktop` (32px). Accommodates concurrent visual panes: live wheel trajectory, real-time agent decision log, Monte Carlo simulation graph, and bet allocation ledger.
- **Tablet (768px - 1279px)**: 8-column layout with 16px gutters and 24px margins. Peripheral telemetry panels tuck into slide-over panels or collapsible horizontal tabs.
- **Mobile (< 768px)**: 4-column layout with 16px margins and 12px gutters. Modular widgets collapse into vertically stacked status cards with sticky action bars for model runs.
- **Vertical Rhythm**: Spacing scales strictly using a 4px base (`space-xs` = 4px, `space-sm` = 8px, `space-md` = 16px, `space-lg` = 24px, `space-xl` = 32px), ensuring absolute alignment across telemetry cards and tabular data.

## Elevation & Depth

This system avoids heavy drop shadows, instead relying on tonal layering, sharp outline definition, and ambient ground dispersion to reinforce its crisp analytical quality:

- **Flat Substrate**: The warm ivory base canvas (`#FBF9F5`) serves as Level 0.
- **Card Tier (Level 1)**: Pure white (`#FFFFFF`) containers with a precise 1px perimeter border (`#E2E8F0`) and an ambient, low-opacity warm-slate shadow: `0 1px 3px rgba(30, 41, 59, 0.04), 0 6px 16px -4px rgba(30, 41, 59, 0.03)`.
- **Active / Interactive Tier (Level 2)**: Hover states, active agent cards, and selected wheel sectors elevate via `0 4px 6px -1px rgba(30, 41, 59, 0.06), 0 10px 20px -3px rgba(30, 41, 59, 0.05)`.
- **Floating Overlays (Level 3)**: Modals, parameter configurations, and live spin inspectors gain an elevated presence: `0 12px 28px -4px rgba(30, 41, 59, 0.08), 0 8px 10px -6px rgba(30, 41, 59, 0.04)`.
- **Inner Depth**: Inset metrics fields, terminal consoles, and agent memory slots use an ultra-subtle inset shadow `inset 0 1px 2px rgba(15, 23, 42, 0.04)` over a faint warm-gray background (`#F8FAFC` or `#F6F4EE`).

## Shapes

The geometric framework is calculated and uniform:
- Standard buttons, input fields, badges, and card boundaries default to `0.5rem` (8px), communicating structural stability without feeling rigid or playful.
- Primary modules and surface containers utilize `1rem` (16px, `rounded-lg`) to gently frame internal tabular elements.
- Roulette outcome chips, model status pips, and cycle indicators use pill/circular geometry (`9999px`) to match the circular physical nature of the wheel, betting tokens, and status beacons.

## Components

### Buttons
- **Primary Execution (Teal)**: Solid `#0D9488` background, `#FFFFFF` text, subtle top highlight border. Hover states shift to `#0F766E`. Active state applies a slight scale compression (`0.98`).
- **Secondary (Indigo)**: `#4F46E5` background, `#FFFFFF` text, shifts to `#4338CA` on interaction. Dedicated to configuration, algorithm switching, and batch simulation starts.
- **Ghost / Analytical**: White surface with 1px `#E2E8F0` border, `#1E293B` text, shifting to `#F1F5F9` on hover. Used for export, log filtering, and view adjustments.

### Status Chips & Roulette Tags
- **Roulette Chips**: Circular badges displaying winning numbers. Red chips use `#DC2626` background with white text; Black chips use `#1E293B` background with white text; Zero uses `#059669` background with white text.
- **Agent Status Chips**: Monospaced pill indicators. "RUNNING" pulses with `#0D9488` dot; "OPTIMIZING" uses `#4F46E5`; "DEFENSIVE_HOLD" uses `#D97706`.

### Cards & Module Containers
- Rendered in crisp `#FFFFFF` with 1px `#E2E8F0` border.
- Headers are divided from module bodies by a 1px border rule. Include an upper-left title set in `headline-sm` with a right-aligned monospaced performance metric in `label-sm`.

### Input Fields & Parameter Controls
- Background `#FFFFFF` with `#CBD5E1` border, transitioning to a focused teal ring (`0 0 0 2px rgba(13, 148, 136, 0.2)`) and `#0D9488` border.
- Floating parameter steppers, learning rate sliders, and stochastic probability inputs display values continuously in `JetBrains Mono`.

### Checkboxes & Toggle Switches
- Checkboxes feature sharp 4px corners, using primary teal fill with an optical white checkmark when active.
- Toggles utilize a sliding pill track with smooth spring animation, turning from `#E2E8F0` (inactive) to `#0D9488` (active).

### Data Tables & Decision Stream Lists
- Alternate row striping using `#FFFFFF` and faint `#FAF8F5`.
- Column headers are set in `label-sm`, uppercase, muted slate (`#64748B`), with bottom border accentuation.
- Real-time updates trigger a subtle 400ms flash in primary teal or crimson before resting.

### Domain-Specific Components
- **Wheel Vector Inspector**: Circular radar/sector diagram marking hot and cold sectors with emerald (`#059669`) and crimson (`#DC2626`) density arcs.
- **Autonomous Agent Thought Stream**: Monospaced terminal window with a `#F6F4EE` background, displaying step-by-step heuristic reasoning, Kelly criterion calculations, and probabilistic confidence scores.
